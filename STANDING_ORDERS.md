# STANDING_ORDERS.md — завещание комплекса

**Аксиома основателя (2026-11-11):** представим день, когда прийти некому и
написать некому — а продукт живёт. Чтобы этот день не стал моментом, когда
комплекс замрёт в ожидании человека, комплекс измеряет молчание основателя
(`harness/succession.py`, свидетель — журнал `data/telegram_history.txt`).
Когда молчание превышает порог (`config.yaml → succession.silence_days`,
по умолчанию 14 суток), комплекс переходит в **РЕЖИМ НАМЕСТНИКА** и
действует по этому документу — и называет это в каждом отчёте. Правление,
сменившееся молча, — не преемственность, а переворот.

Пока строки `SIGNED:` внизу нет, завещание спит: режим наместника тогда
означает только одно — комплекс честно называет, чего (и сколь долго) он
ждёт.

## Полномочия наместника (вступают в силу по подписи основателя)

1. Продолжать все самовозрождающиеся циклы, письма и облака без изменений:
   комплекс не имеет права «увянуть врозь» только потому, что его никто не
   окликнул.
2. Переразмечать флот, маршрутизацию и поставщиков по живым замерам —
   в рамках постоянных порогов и запретов, записанных в `config.yaml`
   (включая `banned_vendors`).
3. Переразвертывать инфраструктуру: саморегистрация через документированные
   API и собственные протоколы поставщиков; перенос канала к следующему
   поставщику, когда прежний умер, — по измеренной карте дверей. Каждый
   перенос фиксируется в публичном журнале.
4. Расходовать собственные бесплатные квоты (Actions, NIM, поисковые тиры)
   по своему усмотрению — в рамках честности и собственных анти-DDoS
   лимитов (одна попытка, не штурм).
5. Кузница (форж): **[строка основателя]** — сливать green-патчи в main
   самостоятельно либо держать их на ветках до оживления основателя.
   Без вписанного решения кузница ведёт себя по-старому: только ветки.
6. Секреты: новые — только собственные, полученные через документированные
   двери и запечатанные в vault. Чужие учётные данные не создавать,
   платежи не проводить: платёжных инструментов у комплекса нет, и без
   основателя они не появляются.

## Что не меняется никогда (в любом режиме)

- Ответ только из фактов; «не измерено» никогда не заменяется нулём или
  догадкой.
- Публичная история репозитория не переписывается.
- Каждый отчёт называет правление: основатель или наместник.
